# Privacy Policy

Last updated: November 27, 2026

This application ("MakzhanMemeBot") is a personal, single-user tool created and operated by Makzhan Karimbayev ("the Owner").

## What the app does
The app reads pins from the Owner's own Pinterest board using the official Pinterest API (read-only access) and forwards them to the Owner's Telegram and Discord channels on a schedule.

## Data we access
- Public metadata and media URLs of pins on the Owner's own board.
- The app does not access any other user's data and does not publish, edit, or delete anything on Pinterest.

## Data storage and sharing
- The app stores only pin IDs and media URLs in a local database on the Owner's server, to avoid sending the same pin twice.
- No data is sold, shared with, or disclosed to third parties.
- The app does not collect personal information from any other users.

## Security
API tokens are stored in a private environment file on the Owner's server and are never published.
